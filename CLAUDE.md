# Верстак — трекер задач команды

Прочитай `ТЗ_и_задачи.md` целиком, прежде чем писать код. Там область работ, модель данных,
список задач по этапам и критерии готовности каждой.

## Правила работы в этом проекте

- Отвечай и комментируй код на русском. Названия переменных, файлов и полей — латиницей.
- Работай по одной задаче из списка за раз. Задача считается сделанной только когда
  выполнен её критерий готовности, а не когда написан код.
- После каждой задачи: прогони проверку в браузере (см. раздел «Как проверять»),
  затем один коммит с номером задачи в заголовке, например `T-07: перетаскивание карточек`.
- Не добавляй зависимости без нужды. Разрешены: `vite`, `typescript`, `firebase`.
  Любая четвёртая — только после вопроса.
- Не трогай `firestore.rules` мимоходом: правила меняются отдельной задачей и отдельным коммитом.
- Ничего из рабочих файлов КОТ в этот репозиторий не копируется. Здесь только код.
- Если упираешься в решение, которое меняет архитектуру (другая база, фреймворк, платный тариф) —
  остановись и спроси, не переписывай молча.

## Быстрые команды

```
npm run dev      # локальный запуск
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное
```
